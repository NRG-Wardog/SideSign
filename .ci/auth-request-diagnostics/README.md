## Wire

`ar1` is <=1024 ASCII bytes: 9 semicolon fields (version, cumulative auth ordinal, cumulative request ordinal, overflow, truncation, current auth boundary, boundary validation, current request detail or `-`, up to 3 prior summaries). Current detail is exactly40 comma fields; summaries are exactly8 fields, indices0,1,2,8,10,24,33,34. Prior records are explicitly history, not causal failure evidence. New auth invocations/acquisitions clear current detail and request-header provenance while retaining bounded prior history. Provider observation is an independent latest immutable acquisition event, explicitly requestAssociation=unobserved. A local handle prevents a later request from stealing earlier consumer validation.

Detail: auth ordinal; request ordinal; phase; method; initial endpoint class; relative start ms; response duration ms; timing cap; outcome; transport class; HTTP; final endpoint; final URL relation; redirect history always `u`; request bytes; response bytes; byte caps; MIME; body shape; parser; plist root; JSON root; envelope fallback; Status shape; strict EC; strict HSC; original EC cast/default; effective EC; EC source; 15-key CPD primitive schema/container; Retry-After form; bounded seconds; cap; consumer gate; consumer outcome; reason; response-observed; unexpected CPD count capped32; actual service/header-version envelope classes; serialization.

Strict numeric diagnostics reject bool/string/floating/other/out-of-range with distinct closed tokens without changing protocol behavior. HSC is canonical100...599, EC is canonical ±99999999. Zero auth/request with no detail is accepted only for an explicitly observed pre-request serialization failure. An absent redirect observer is never represented as zero redirects. No raw URL, body, headers, secrets, messages, identifiers, blobs or their hashes are retained/exported.
